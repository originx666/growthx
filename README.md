# 歌若思

歌若思：一个本地开源免费的通用型终身成长生态中心，帮助用户在了解自我后进行项目制学习和学习生涯数据管理。

## 设计背景
开发者认为当前AI对教育行业的改变只不过是提升了本身教育系统的效率，市场上并没有出现一款真正为未来教育而服务的产品。
教育不应该是为了让某一个系统更加稳定而存在，它应该是为了帮助人类去追求真理和自身的幸福而存在，而这也是我始终追求的目标，基于这样的理念，我设计了歌若思这款产品，它将会超越网上比较流行的个人工作台（只专注于打卡和清单之类的功能，非常反人性，而且基本要收费），它融入了本人全部对教育的思考。

了解更多个人的教育理念：https://docs.qq.com/aio/p/sc2105945qzewp3?p=0MUNKHQ1dP5Nj7EPcjJlC1

可以实现的功能主要包含以下内容：

## 自我探索
分为5个维度来帮助大家了解自我，找到自己的梦想，并帮助实现，五个维度主要包含：霍兰德职业兴趣、职业、社会价值观、大五人格、多元天赋能力，最终帮助用户了解自己的北极星梦想，确定当下的阶段罗盘并创造项目完成，同时以上内容支持导出提示词或者直接进行AI分析。

## 项目制学习
主要采用OKR的方式创建、拆解项目，无限项目节点，支持项目时间轴，分享并导入项目包（导入后相关的学习资质显示未完成）。

## 项目画布

打开任意项目，画布入口位于“总览”的项目详情卡片下方。首次进入可创建空白画布，保存后会在总览中生成本地缩略图。顶部栏目依次为“总览 / 节点 / 关联”，右侧 AI 问答独立于栏目切换。

- 支持从左侧工具栏把文字、便签、矩形、椭圆、思维节点、图片、本地文件卡片、网页卡片和容器拖到指定位置；落下后使用预设样式。
- 选择“连线”后依次点击两个元素即可建立关系。
- 元素可拖动、调整大小和修改文字/填充样式；支持撤销、重做、缩放与适应内容。
- `Ctrl+S` 保存，`Ctrl+Z` 撤销，`Delete` 删除选中元素，双击文字类元素可直接编辑。
- 有未保存修改时退出编辑器，会提示保存、不保存或继续编辑。
- 每个项目的画布相互独立，全部保存在本机当前账号的数据中。

## 学习生涯数据沉淀
支持记录自身的领域、技能、阅读、课程、证书的学习生涯数据记录，将自身数字化，让AI给自己提供建议。

## 隐私与存储

- 项目、学习生涯、个人资料和对话历史都保存在当前 Windows 用户的本地应用数据目录。
- 不连接 Supabase、Netlify 数据库或其他云端存储。
- 邮箱只用于在同一台电脑上区分本地账号，不会发送到网络。
- AI 问答只连接本机 `127.0.0.1:11434` 上的 Ollama，学习数据不会发送到云端。

Windows 数据通常位于 `%APPDATA%\歌若思\Local Storage`。卸载前如需保留数据，请备份整个 `%APPDATA%\歌若思` 目录。

## 开发运行

需要 Node.js 20 或更高版本。

```bash
pnpm install
pnpm start
```

## 构建 Windows 安装包

```bash
pnpm build:win
```

构建结果位于 `release` 目录，包含安装版和便携版。

## 可选：启用本地 AI

1. 安装 [Ollama](https://ollama.com/)。
2. 执行 `ollama pull qwen2.5:7b` 下载中文模型。
3. 保持 Ollama 在本机运行，再打开歌若思使用 AI 问答。

可通过环境变量 `GERUOSI_OLLAMA_MODEL` 更换模型。
